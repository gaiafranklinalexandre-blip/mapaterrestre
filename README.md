# Mapa terrestre APS

Visualizacao online leve para apoiar o mapeamento de unidades moveis e pontos de apoio relacionados ao projeto de conectividade APS.

## Camadas

- MCom 177: unidades enviadas pelo Ministerio das Comunicacoes.
- UBSF SCNES: coordenada cadastral das UBSF no SCNES.
- Apoios estimados: pontos de apoio com coordenadas estimadas apenas para visualizacao exploratoria.

## Uso

Abra `mapa_online/index.html` em um navegador.

Para publicar no Render como site estatico, use:

- Publish directory: `mapa_online`
- Build command: vazio

## Observacao

As coordenadas dos pontos de apoio sao estimativas visuais de baixa confianca. Elas nao devem ser usadas como localizacao oficial, rota operacional ou decisao de instalacao.
